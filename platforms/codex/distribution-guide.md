# LingMind 分发与连接方式

LingMind 处理业务，LingMind Operator 处理环境运维。选择适合宿主的一种安装来源，更新时保留既有身份，避免同名副本。

| 分发方式 | 连接方式 | 适用范围 |
| --- | --- | --- |
| Git 仓库或原生 ZIP | 原生 MCP 与独立 OAuth | 支持原生 MCP 的桌面端及 CLI |
| App 插件 | 已注册 App 与宿主管理的授权 | 支持该 App 的宿主；可用范围由宿主授权决定 |

[仓库安装说明](repository/README.md)与[云端打包说明](cloud-plugins.md)分别描述两种路径。
新增业务连接时提供确切环境代码，完成该环境独立授权。Operator 使用单独的授权入口。
生成 ZIP、安装插件和成功调用服务是不同的验证步骤；不能由文件存在推断运行可用。

账号配置、发布回执和环境验证结果保存在私有工作区，不进入公共仓库或分发包。
