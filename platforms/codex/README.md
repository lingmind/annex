# Codex integration

LingMind provides two plugins: LingMind for business operations and LingMind Operator for environment operations.

Choose a distribution matching the host:

- [Repository plugins](repository/README.md) use native MCP and independent OAuth connections on desktop or CLI.
- [Cloud packages](cloud-plugins.md) use registered App dependencies and host-managed authorization.

See the [distribution guide](distribution-guide.md) and [environment connection contract](user-environment-connections.md).
Source packages describe capabilities; installation, authorization and successful runtime calls must be verified separately.
Keep account-specific bindings and verification receipts outside public source according to the [public content policy](../../docs/public-content-policy.md).
